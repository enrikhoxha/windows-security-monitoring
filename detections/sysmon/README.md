# Sysmon Monitoring

This directory documents the Sysmon telemetry used for endpoint monitoring and investigation.

## Primary Event IDs

### Event ID 1 - Process Create
Used to review process execution, parent/child relationships, image paths, and command-line context.

### Event ID 3 - Network Connect
Used to connect network activity back to the originating process and review destination addresses, ports, and protocols.

### Event ID 22 - DNS Query
Used to review DNS activity generated by endpoint processes and correlate domain lookups with subsequent network connections.

## Investigation Pattern

A common workflow is:

```text
Process creation
      |
      v
DNS query
      |
      v
Network connection
      |
      v
Firewall / network confirmation
```

This sequence can help reconstruct activity and determine whether endpoint behavior is expected or requires further investigation.

## Publishing Standard

Any examples added here should use sanitized event data and avoid exposing real internal infrastructure details.
