# Screenshots

This directory is reserved for sanitized screenshots that support the technical documentation in this repository.

Suitable examples include:

- Wazuh dashboard views
- Sysmon event examples
- Windows Event Viewer evidence
- Detection validation screenshots
- Architecture or telemetry diagrams

Before publishing an image, remove or obscure:

- Internal IP addresses
- Hostnames or domain names
- Usernames and email addresses
- Customer or organization identifiers
- Credentials, tokens, or keys
- Any information that could expose private infrastructure

Screenshots should be included only when they add useful evidence or explain an investigation step more clearly than text alone.
